Evidence + authority

The system knows what it can do — and what it cannot.

A student intelligence layer should not turn every explanation into a fake institutional action.

Evidence before assertion

Official NOUN material is preferred for current institutional facts. When evidence is missing or stale, ABBA can use current web search where the system permits it and show the source path.

User control before execution

Submitting a consequential request, representing a student, moving money or making an institution-authorised decision stays inside the appropriate boundary.
