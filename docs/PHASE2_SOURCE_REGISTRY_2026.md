## Source policy

- Prefer official institutional/regulatory sources.
- Record source URL, retrieval time, content hash and parser version.
- Do not silently merge contradictory official sources.
- Preserve source versions when rules or programme structures change.
- Material claims require evidence references.
- External providers must be labeled external and independently verified before inclusion.
- Financial providers must not be presented as endorsed by NOUN or Carbon Actual unless there is an explicit documented relationship.

## Data classes

A = authoritative institutional/regulatory
B = institution-linked official
C = verified external provider
D = unverified discovery

ABBA may answer directly from A/B sources. C requires clear external attribution and current verification. D may be surfaced only as an unverified lead, never as an authoritative fact.
