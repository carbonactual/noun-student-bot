# ABBA ↔ NOUN Architecture

ABBA is the master intelligence and orchestration AI of the Carbon Actual ecosystem. The NOUN Student Intelligence node is a bounded domain deployment under ABBA.

## Boundaries

ABBA: orchestration, cross-domain reasoning, source intelligence, insight generation, recommendation, campaign orchestration and governance.

NOUN node: NOUN knowledge, student academic state, programme/course graph, examinations, assessments, student services, opportunities and WhatsApp interaction.

## Intelligence loop

`observe -> verify -> understand -> match -> recommend -> approve -> communicate -> measure -> learn`

## Communication rule

No raw source change becomes a broadcast automatically. The ABBA decision layer classifies events and requires verification/confidence thresholds before student communication or campaign review.

## Privacy

Student-specific state remains in the NOUN domain. ABBA should receive only the minimum data required for an authorized intelligence operation; aggregate insight should be preferred for ecosystem analytics and campaigns.
